# Jev固定資料評価（Issue #51 / PR #53）

モデル実行前に `test/fixtures/jev-evaluation/{corpus,questions}.json` を固定する。5群×8問、各群の前半4問は開発用、後半4問は評価用。開発用を調整に使い、評価用の結果を見て調整した場合はその集合を未使用評価集合とは呼ばない。原質問は必須回帰として扱う。

資料は既存の公開本文fixture40区間と公開検索のバス関連43区間、明示的に架空と記した地域の台帳・有効化集合・旧時点・未マージ案・非公開資料5区間の計88区間。公開資料は選択バイアスのある抜粋であり、全国母集団でも、本番索引の無作為標本でもない。元の本文区間ID・URL・メタデータを保持し、同一sourceの本文をordinal順に結合した固定索引をSQLiteへ作る。両方式に同じ索引を使う。現行のRust/WASM APIを通し、DBのみローカルfixtureに置換する。旧方式のRustコアはバックアップから変更していない。

正解ラベルは資料に書かれた事実と必要な本文IDの組。`required_groups`の各群は少なくとも1区間を回収すれば成立する必須事実、`relevant_ids`は当該質問の根拠として許容する区間、`fact`はラベルの根拠。ラベルをモデルの取得結果へ合わせて変更しない。誤ラベルが見つかった場合は変更と理由を記録し、旧ラベルの結果も保持する。

## 指標と合否

- 各方式・各質問を3回実行。モデル異常の2問は障害対照であり、通常の関連性精度から除外する。
- 必須事実回収率 = 回収したrequired_groups / 全required_groups。根拠がない問題に再現率を捏造しない。
- 無関係率@10 = 取得上位最大10件のうちrelevant_idsにない割合。結果0件なら0。件数が多いことを精度の高さとみなさない。
- 必須根拠ありなのに0件となる率、必須ケースの全回収、無関係質問の偽陽性を別記する。
- 脱落は本文を読む前の文書選択か、読んだ後の本文判定かを、実際のDB取得IDから分類する。
- 公開資料だけをモデルへ渡すことを検査。非公開fixtureの固有マーカーが入力へ出たら漏出。
- モデル停止と不正応答は502で返り、hit_countを持つ成功応答へ変換されないことを検査する。これら2問は実モデル障害を意図的に起こさず、境界へ障害を注入する。
- 最低ゲート: 必須回帰ケースは3回とも必要根拠回収、漏出0、障害の0件化0。評価用の事実回収率は現行以上、無関係率@10の悪化は5ポイント以内。未達なら不合格と報告する。
- p50/p95、呼出し数、入出力トークンも記録。ローカルSQLite＋遠隔モデルの時間を、本番D1の応答時間と同一視しない。

これは検索精度の評価。架空台帳の正解算術値は分散根拠のラベル付けに使うが、現在のAPIに未実装の集計機能や文章生成の正確性を合格扱いしない。

## 実モデルの実行

`.github/workflows/evaluate-jev.yml` は `evaluation/jev-*` ブランチへのpushで開発用を実行する。`evaluation/jev-heldout-*` なら評価用。APIキーを環境外へ取り出さず、既存WorkerのSecretを継承する評価専用バージョンをアップロードする。本番トラフィックは切り替えない。エントリはモデル呼出しだけでDBを持たず、ランダムな一時トークンで認証し90分後に拒否する。トークンはActionsログでマスクする。モデル入力・出力に秘密値を入れない。

評価本体はNode/SQLiteと実Rust/WASMの同じAPIを使用し、モデル通信だけをこの一時経路へ通す。ラベルはモデル入力へ送らない。結果はActions artifactへ保存し、採用した結果と比較報告を本PRへ収録する。失敗・非200・空の応答も残し、成功した実行だけを選ばない。

## 第1回の結果と第2回の扱い

第1回は開発用20問を実行し、実装・閾値を変えずに評価用20問を実行した。開発用は必須事実回収率75.9%→100%、無関係率25.2%→18.9%だった。一方、評価用は回収率63.6%→95.5%だが無関係率18.8%→30.4%となり、5ポイント以内のゲートを超えて**不合格**。この結果を保持する。

第2回では、本文判定を「話題が関連する」から「質問の指定対象・観点に対して、明記された具体的事実または必要な計算入力を提供する」へ明確化する。数値閾値0.5は変えない。個別の質問・バス固有語・事業者名の例外は追加しない。

第1回の40問は以後すべて開発資料として扱い、ラベル自体は変更しない。`questions-v2.json`の新しい20問を、この修正の実測前に固定した。同じコーパスに対する新しい質問であり、未知の文書群や別ドメインへの汎化を示すものではない。第2回の開発は元40問（split=all）、最終評価はv2の20問。合否条件は変更しない。

固定比較では同期で生成する語彙辞書は空で、Rustコア内蔵の辞書は有効。本番で既に生成された語彙辞書を含む全索引そのものとの精度比較ではない。資料抜粋の選択バイアス、アシスタントが作成した事前ラベル（人手の二重注釈は未実施）、計算・生成回答が評価対象外であることを結果と一緒に明記する。

- 評価: run `43675581779` / artifact `14146580771`
