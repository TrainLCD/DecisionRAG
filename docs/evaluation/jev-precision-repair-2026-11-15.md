# Jev検索の未達条件への修正・再評価（2026-11-15）

**採用版v9は、100問・追加20問・別表現20問の全セットで既定の合格条件を満たした。**
必須資料の欠落、根拠がある質問の0件化、通常要求のエラー、非公開資料の漏洩、障害の空結果化はいずれも0。ただし一般質問の全根拠を100%回収する実装ではない。以下に未回収の根拠も記録する。

## 修正

1. 保存済みの長い本文区間を、推論時だけ見出し・段落単位に分ける。元の引用ID・本文は保持し、コードブロックと全バイトを維持する。区間スコアは最大値で元の引用へ統合し、重複や長さによる加点をしない。
2. タイトル・識別情報・リリース情報は先頭区間の本文と合わせて評価する。後続区間へタイトルの根拠を繰り返し転用しない。
3. Jevの非生成判定で質問の種類を先に決める。集計質問は同じ対象集合・データセットかを照合し、通常質問は対象・機能・操作・プラットフォーム・明示的関係を照合する。意図判定は追加探索でも再利用する。
4. 集計ではメンバー・単位・包含除外条件・欠落条件を評価する。通常質問では求められた事実・理由・制約を直接示すかを評価し、一般的な準備・構成説明を除外する。

閾値0.5、必須根拠、公開範囲、予算上限、品質ゲートは変更していない。質問文・ソースID・バス用キーワードによる例外処理は実装していない。

## 条件と結果

固定88区間・52資料、各問3回、旧Rustと同一資料で比較。実Rust/WASM検索APIから実際のJev 1.14.0を呼び出した。100問と追加20問は開発中に結果を確認した回帰集合。別表現20問はv8結果確認前に固定し、v9の変更をその20問の結果を見る前に確定した。ただし資料・正解事実は同じで、新規ドメインへの一般化評価ではない。ラベルはアシスタント作成で、人手の二重確認はない。

|---|---|---:|---:|
